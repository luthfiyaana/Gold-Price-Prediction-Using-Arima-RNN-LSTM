# Prediksi Harga Emas Menggunakan ARIMA, RNN, dan LSTM

## Deskripsi Proyek

Proyek ini merupakan implementasi machine learning untuk melakukan prediksi harga emas harian menggunakan pendekatan time series forecasting. Penelitian dilakukan dengan memanfaatkan data historis harga emas untuk mempelajari pola pergerakan harga dan menghasilkan prediksi berdasarkan model yang dikembangkan.

Tiga metode yang digunakan dalam proyek ini adalah **ARIMA (AutoRegressive Integrated Moving Average)**, **Recurrent Neural Network (RNN)**, dan **Long Short-Term Memory (LSTM)**. Ketiga model tersebut dikembangkan dan dibandingkan untuk mengetahui perbedaan performa dalam memprediksi harga emas.

## Tujuan

- Mengembangkan model prediksi harga emas harian menggunakan pendekatan time series.
- Menerapkan dan membandingkan model ARIMA, RNN, dan LSTM.
- Mengevaluasi performa model menggunakan metrik MAE, RMSE, MAPE, dan R².
- Menganalisis hasil prediksi dan mengidentifikasi model dengan performa terbaik.

## Metode

1. Exploratory Data Analysis (EDA)
2. Data Preprocessing
3. Time Series Forecasting menggunakan ARIMA
4. Model Development menggunakan RNN dan LSTM
5. Model Evaluation dan Comparison
6. Gold Price Forecasting

## Hasil

Berdasarkan evaluasi yang dilakukan, model LSTM menghasilkan performa prediksi terbaik dibandingkan ARIMA dan RNN. Hasil evaluasi menunjukkan bahwa pendekatan deep learning, khususnya LSTM, memiliki potensi yang baik dalam mempelajari pola pergerakan harga emas berdasarkan data historis.

Proyek ini dikembangkan sebagai bagian dari mata kuliah Data Mining.
