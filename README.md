# Gold-Price-Prediction-Using-Arima-RNN-LSTM
Proyek prediksi harga emas harian menggunakan metode time series ARIMA, Recurrent Neural Network (RNN), dan Long Short-Term Memory (LSTM). Proyek ini bertujuan membandingkan performa ketiga model dalam memprediksi harga emas berdasarkan data historis serta menganalisis hasil forecasting menggunakan metrik evaluasi.
